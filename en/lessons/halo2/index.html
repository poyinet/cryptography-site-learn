Halo2

Level 4algorithm零知识证明

这一课要解决什么

By the end, you can explain what “Halo2” solves, which assumption it relies on, and at least one boundary where it fails.

Algorithm : Halo2 (Halo2 证明系统). The PLONKish matrix Halo2 writes a circuit as a matrix: columns are advice, fixed or instance, and rows are gates. Each gate is a polynomial constraint linking neighboring rows and multiple columns; a custom gate can read several columns at once, and a lookup argument constrains a column's values …

为什么值得读

Halo2 needs no trusted setup: public parameters come from fixed curves, so there is no “toxic waste”. PLONKish columns and gates are customized to the circuit, lookups make 8-bit/16-bit range checks cheaper than long constraint chains, and IPA relies only on discrete logarithms, not pairing curves.…

边界与攻击面

No trusted setup does not mean no trust: the constraint system, lookup tables and public inputs are defined by the application. A missing or wrong gate can let a proof “prove” a false statement. IPA verification is not constant-size, and a recursive verifier consumes many rows; proving time scales with circuit size, column count and lookup count.…
