这一课要解决什么

By the end, you can explain what “Shamir Secret Sharing” solves, which assumption it relies on, and at least one boundary where it fails.

Algorithm : Shamir Secret Sharing (Shamir 门限秘密共享). Shamir's Secret Sharing (SSS) answers a very plain question: how do you split one key into n pieces so that any t of them put it back together, and one short leaves you none the wiser? The mechanism is polynomial interpolation .…

为什么值得读

Shamir sharing solves the most counterintuitive problem in key management: sometimes the safest way to keep a key is to break it up. A key sitting in a safe is a single point of failure: crack the safe and it's gone, lose the safe and it's gone. Split it into three and give one to each of three people, and: - Two colluding insiders still cannot get in (a 3-of-5 threshold).…

边界与攻击面

Shamir's mathematics has no weaknesses. The number of ways it fails in practice is long enough to be worth a list. - "Split" is not the same as "spread". The most common failure: a 3-of-5 split whose five shares all sit in the same cloud account, the same mailbox, the same folder on the same laptop. That is no split at all — one share is enough.…
