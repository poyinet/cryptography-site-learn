Chinese JSON Object Signing and Encryption

Level 4standard中国国密

这一课要解决什么

By the end, you can explain what “Chinese JSON Object Signing and Encryption” solves, which assumption it relies on, and at least one boundary where it fails.

Standard : Chinese JSON Object Signing and Encryption (国密 JSON Web 语法). GM/T 0125.2—2022 JWS has a JOSE header, payload and signature. The protected header is UTF-8 then base64url: \(protected\ b64=base64url(UTF8(header))\); the payload is \(payload\ b64=base64url(payload)\).…

为什么值得读

Chinese JOSE is not just “JWT with a different signature algorithm”. It treats \(alg\) as the algorithm identifier, \(kid/jwk/x5c/x5t sm3\) as key identifiers, and separates protected from unprotected headers; a verifier that reads only the \(alg\) string without checking the key type repeats JWS algorithm confusion.…

边界与攻击面

There are four boundaries. First, unprotected headers are outside the signature and can be changed; any header that affects a security decision belongs in the protected header. Second, \(alg\) and key type must bind: treating an SM2 public key as an HMAC key or accepting \(none\) breaks verification.…
