这一课要解决什么

By the end, you can explain what “GM/T 0003-2012 SM2 Public Key Cryptographic Algorithms” solves, which assumption it relies on, and at least one boundary where it fails.

Standard : GM/T 0003-2012 SM2 Public Key Cryptographic Algorithms (GM/T 0003-2012 SM2 椭圆曲线公钥密码算法). GM/T 0003-2012 divides SM2 into general, digital signature, key exchange, public-key encryption and parameter definition.…

为什么值得读

SM2 is not “ECDSA with another curve”. Z A binds the user identity, curve parameters and public key into the signed input, so the same message yields different e under different identities or parameters; the (1+d A)^-1 factor in s also differs from ECDSA’s k^-1 form.…

边界与攻击面

Reusing, predicting or sharing k across devices exposes the private key through repeated r; checking only r,s ranges without t≠0 can accept degenerate inputs. A wrong Z A concatenation order, ENTL byte order or ID encoding breaks interoperability. SM2 is a public-key system: certificates, name constraints and revocation still bind the key. Signing gives no confidentiality; encryption gives no signer authentication.…
