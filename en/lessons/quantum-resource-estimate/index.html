Attack : Quantum Resource Estimation (量子资源估算). From algorithm to resources Shor’s algorithm reduces integer factoring to order finding: choose a, find the least r 0 with a^r ≡ 1 (mod N), then use gcd(a^{r/2}±1,N) to obtain a factor. Elliptic-curve discrete logarithm reduces to period finding: given Q=[k]P, find k.…

为什么值得读

“A quantum computer can break RSA” is an algorithm-level statement; “2048-bit RSA can be broken before a given year” needs a physical-layer ledger. Resource estimation separates the two and lets migration plans discuss parameters, time windows and uncertainty instead of a slogan. NIST post-quantum migration does not start when a quantum computer appears.…
