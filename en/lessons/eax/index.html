EAX

Level 3algorithm消息认证与 AEAD

这一课要解决什么

By the end, you can explain what “EAX” solves, which assumption it relies on, and at least one boundary where it fails.

Algorithm : EAX (EAX 认证加密). A two-pass AEAD mode EAX encrypts with CTR mode, then authenticates the nonce, header and ciphertext with OMAC; the tag is the XOR of the three values, truncated. It is a two-pass AEAD: first M becomes C, then three values over N, H and C are XORed and truncated into the tag.…

为什么值得读

EAX’s niche is simple, provable, patent-free two-pass AEAD: it avoids CCM’s elaborate length encoding and supports arbitrary-length nonces, headers and messages, with truncatable tags. For developers the API is just encrypt/decrypt, which reduces the chance of miscombining encryption and a MAC. It trades two passes for simplicity and a security proof.…

边界与攻击面

EAX security depends on nonce uniqueness and on the block cipher being a PRP. Nonce reuse is the direct attack surface: CTR keystreams repeat and tags can become forgeable. EAX does not hide the nonce; the nonce is authenticated but not secret. It is two-pass, so encryption must finish the message before the tag is known, which rules out very low-latency streaming.…
