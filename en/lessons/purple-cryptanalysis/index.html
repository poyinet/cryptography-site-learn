By the end, you can explain what “Purple Cryptanalysis” solves, which assumption it relies on, and at least one boundary where it fails.

Attack : Purple Cryptanalysis (紫密破译). The 6-20 structure Purple, the Japanese Type 97 alphabetical typewriter, maps 26 letters through an input plugboard into an internal alphabet fixed as six “sixes” and twenty “twenties”.…

为什么值得读

The Purple break shows that a large key space is not the same as security: a fixed 6-20 partition splits 26! into 6!·20! and makes statistical identification possible. It relies on finding a structural invariant before rebuilding the stepping, not on raw machine speed. This is the break mechanism; the machine--purple entry covers the machine structure.…

边界与攻击面

1. Structural change: if the partition is no longer 6-20, the statistical separation and the 6!·20! reduction fail. 2. Insufficient known plaintext: without a crib, the stepping phase is hard to fix. 3. Message variation: transcoding, abbreviations or padding destroy the pattern. 4. Non-unique settings: short messages can leave several candidates and need a second passage. 5.…
