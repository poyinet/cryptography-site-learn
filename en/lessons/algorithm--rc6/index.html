RC6

Level 3algorithm对称分组密码

这一课要解决什么

By the end, you can explain what “RC6” solves, which assumption it relies on, and at least one boundary where it fails.

Algorithm : RC6 (RC6 分组密码). RC6 is the parameterized block cipher RC6-w/r/b: the block is 4w bits, the key is 8b bits, and it runs r rounds. The AES submission uses w=32, r=20 and b=16/24/32, i.e., a 128-bit block, 128/192/256-bit keys and 20 rounds. The 128-bit block is split into four 32-bit registers A, B, C and D.…

为什么值得读

RC6's design goals are simplicity, speed, compactness and security. It uses only addition, subtraction, multiplication, XOR and rotation, operations that modern processors handle well, so it suits software implementations; the AES submission uses a 128-bit block, 20 rounds and 128/192/256-bit keys.…

边界与攻击面

RC6's claims that the best attack is exhaustive search, that differential/linear data exceeds available data and that no weak keys are known are designer assessments in the 1998 submission, not formal proofs against every attack model, and they do not guarantee that no better analysis will appear.…
