Quantum Collision Search

Level 4attack后量子

这一课要解决什么

By the end, you can explain what “Quantum Collision Search” solves, which assumption it relies on, and at least one boundary where it fails.

Attack : Quantum Collision Search (量子碰撞搜索). Classical collision search For an n-bit hash, sampling about 2^{n/2} inputs finds a collision with high probability by the birthday paradox. This is optimal up to constants in the classical black-box model: Ω(2^{n/2}) evaluations. Preimage search needs about 2^n evaluations.…

为什么值得读

If the target is 128-bit security against classical collision attacks, a 256-bit hash suffices (2^{128}). To resist quantum collision attacks, 2^{n/3}=2^{128} needs n≈384. NIST post-quantum signatures such as SPHINCS+ therefore use longer hash outputs or adjusted parameter sets. Treating a 256-bit hash as “still 128-bit collision security under quantum” is a common error.…

边界与攻击面

1. Black-box model. BHT assumes a black-box function; algorithms that exploit the hash internals may do better. 2. Quantum memory model. The algorithm needs quantum RAM or substantial coherent storage; different cost models change constants and feasibility. 3. Collisions only. It does not lower preimage search to 2^{n/3}; Grover preimage remains 2^{n/2}. 4. Asymptotic notation hides constants.…
