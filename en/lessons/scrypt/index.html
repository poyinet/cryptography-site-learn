为什么值得读

scrypt exists for one reason: GPUs and ASICs get cheaper much faster than memory does. Section 1 of RFC 7914 says this bluntly. Every classic password KDF — DES crypt, MD5 crypt, SHA-crypt, PBKDF2, bcrypt — is "iterate plus salt". You can raise the iteration count as hardware improves: keep the user's per-login time constant, and on paper nothing is lost. It is a paper-only peace.…

边界与攻击面

scrypt has not been "broken", but it has failure modes you need to know. - Memory is both its defence and its denial-of-service surface. RFC 7914 §14 warns explicitly that parameters must not come from an untrusted party, or an attacker can specify an absurdly large N and make the server allocate gigabytes.…
