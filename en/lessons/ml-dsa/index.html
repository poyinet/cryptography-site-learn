Algorithm : Module-Lattice-Based Digital Signature Standard (ML-DSA 格基签名). FIPS 204, published 13 August 2024, states: "ML-DSA is a digital signature scheme based on CRYSTALS-DILITHIUM".…

为什么值得读

The standard says "The ML-DSA scheme uses the Fiat-Shamir With Aborts construction". To correct a bias, the signer applies rejection sampling to z; if coefficients of z fall outside of a specified range, the signing process is aborted, so signing is largely a rejection-sampling loop whose iterations either produce a valid signature or "an invalid signature whose release would leak information about the private key".…

边界与攻击面

Signing randomness is the main failure point: for ML-DSA to be secure, the signer's commitment value y must not be used to sign more than one message, and it must not be easily guessed by an attacker. This requires randomness.
