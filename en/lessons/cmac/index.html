CMAC

Level 3algorithm消息认证与 AEAD

这一课要解决什么

By the end, you can explain what “CMAC” solves, which assumption it relies on, and at least one boundary where it fails.

Algorithm : CMAC (CMAC 分组密码 MAC). Section 5.2 of the retained text states the structural relation: "The CMAC algorithm depends on the choice of an underlying symmetric key block cipher. The CMAC algorithm is thus a mode of operation (a mode, for short) of the block cipher.…

为什么值得读

The motive sits in the first sentence of §3, naming the deficiency of what it replaces: "The basic Cipher Block Chaining MAC algorithm (CBC-MAC) has security deficiencies [9]." The text then identifies the core of CMAC as the XCBC variant proposed and analysed by Black and Rogaway. In other words, CMAC exists not to add another MAC but to patch a known weakness of CBC-MAC while still running on a block cipher.

边界与攻击面

Three limits are checkable. First, the replacement relation itself: §3 says CBC-MAC "has security deficiencies [9]", so chaining encryptions and using the result as a MAC is unsafe, and CMAC is the correction. Second, the dependency printed in §5.2: "The CMAC algorithm depends on the choice of an underlying symmetric key block cipher" — a broken block cipher takes CMAC's security with it.…
