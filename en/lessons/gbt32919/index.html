SM2 Digital Signature

Level 3standard中国国密

这一课要解决什么

By the end, you can explain what “SM2 Digital Signature” solves, which assumption it relies on, and at least one boundary where it fails.

Standard : SM2 Digital Signature (SM2 数字签名). Curve and keys SM2 signatures use the 256-bit prime-field curve curveSM2 with base point G of order n. The private key is d∈[1,n−2] and the public key is P=dG. Signing Compute e=SM3(Z A‖M), where Z A binds the user identity, curve parameters and public key.…

为什么值得读

SM2 binds the SM3 digest, curve arithmetic and user identity into one signing flow, fitting certificates, TLS authentication and electronic seals. Unlike ECDSA’s truncated x-coordinate, it closes the loop over e, r and s. SM2 also defines public-key encryption and key exchange; this entry covers signatures only. SM3 is a hash and SM4 a block cipher, with different security goals.

边界与攻击面

1. Nonce reuse: the same d and k over two messages exposes the private key; this is the most direct fatal error. 2. Missing curve/point checks: failing to verify that P lies on curveSM2 with the right order enables invalid-curve or small-subgroup attacks. 3.
