Identity-Based Encryption

Level 4algorithm秘密共享与 MPC

这一课要解决什么

By the end, you can explain what “Identity-Based Encryption” solves, which assumption it relies on, and at least one boundary where it fails.

Algorithm : Identity-Based Encryption (身份基加密). In IBE the public key is not a random number but the recipient's identity string, such as an email address or device ID. A private-key generator (PKG) holds the master key and derives a private key for each identity.…

为什么值得读

It addresses the certificate-distribution pain of public-key infrastructure: a sender needs only an identity, not a prior certificate. That suits email, IoT devices and temporary collaboration. It is also the ancestor of ABE, which widens one identity into an attribute policy. Restate the chain as input → state → transform → output → criterion.…

边界与攻击面

IBE does not prove that an identity string belongs to a person; it only maps the string to a key. The PKG knows every private key, so key escrow is a structural risk; compromise of the PKG compromises all users. Revocation needs extra machinery, or a departed user's old key still decrypts old messages. It does not automatically provide forward secrecy.
