Theorem : Gentry's FHE Construction (Gentry 全同态构造). Gentry first builds a somewhat homomorphic scheme: ciphertexts carry noise, addition and multiplication work, but enough multiplications drown the plaintext.…

为什么值得读

It proved that fully homomorphic encryption exists and ended the impasse in which homomorphic encryption could manage only a few operations. Bootstrapping became a general tool for later FHE schemes; without Gentry there is no modern BFV, CKKS or TFHE ecosystem. Restate the chain as input → state → transform → output → criterion. Every step should identify who acts, what changes and what evidence remains.…

边界与攻击面

The original construction used ideal lattices, with enormous keys and ciphertexts and impractical bootstrapping overhead. It does not guarantee concrete parameter security or address side channels, key management and decryption interfaces. Bootstrapping requires homomorphic evaluation of the decryption circuit; if that circuit is too deep, the construction fails. Theorem = (Assumptions ⇒ Conclusion)；…
