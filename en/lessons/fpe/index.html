Algorithm : Format-Preserving Encryption (FPE 格式保留加密). The 2016 edition of SP 800-38G says format-preserving encryption "is designed for data that is not necessarily binary": for any finite set of symbols such as decimal numerals, the encrypted form "has the same format, including the length, as the original data".…

为什么值得读

Ordinary encryption changes length or character set. The document uses the nine-decimal-digit Social Security number as its example: a longer ciphertext would no longer fit the format.
