SM9 Identity-Based Cryptography

Level 3protocol中国国密

这一课要解决什么

By the end, you can explain what “SM9 Identity-Based Cryptography” solves, which assumption it relies on, and at least one boundary where it fails.

Protocol : SM9 Identity-Based Cryptography (SM9 标识密码). Identity is the public key SM9 is identity-based cryptography: a user’s public key is determined by an identity string (email, ID number, domain name), and the private key is derived by a key generation center (KGC) from the master secret and the identity.…

为什么值得读

SM9’s value is removing certificate chains: the public key is the identity and the KGC derives private keys, which suits IoT, government, email and enterprise intranets where identities already exist. One identity-based standard family covers signatures, encryption, key exchange and KEM, reducing certificate issuance, distribution and revocation overhead.…

边界与攻击面

SM9 security rests on bilinear Diffie–Hellman-type problems, SM3, the KGC master secret and user private keys. Single-point master-key leakage, a malicious KGC, key escrow, pairing side channels, identity-string ambiguity and private-key revocation are real risks. Boundaries: SM9 is not a certificateless decentralized scheme; it concentrates trust in the KGC.…
