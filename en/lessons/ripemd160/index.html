RIPEMD-160

Level 3algorithm哈希

这一课要解决什么

By the end, you can explain what “RIPEMD-160” solves, which assumption it relies on, and at least one boundary where it fails.

Algorithm : RIPEMD-160 (RIPEMD-160 散列). RIPEMD-160 is an iterative hash function with a 160-bit digest; it processes 32-bit words in 512-bit message blocks and keeps a five-word state h0…h4. The initial value is h0=67452301, h1=efcdab89, h2=98badcfe, h3=10325476 and h4=c3d2e1f0.…

为什么值得读

RIPEMD was developed in the EU RIPE (RACE Integrity Primitives Evaluation) project; RIPEMD-160 is the strengthened version proposed in 1996. The paper proposes both the 160-bit RIPEMD-160 and a 128-bit RIPEMD-128 plug-in substitute for RIPEMD; the 160-bit design aims to transfer the confidence built up with RIPEMD to the new algorithm.…

边界与攻击面

RIPEMD-160 uses Merkle-Damgård iteration: the chaining value after each block is the next block's input, and the final output is the chaining value; given H(M) and the length of M, one can length-extend to H(M pad(M) X), which is not a collision.…
