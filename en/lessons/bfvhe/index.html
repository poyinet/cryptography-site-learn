Brakerski-Fan-Vercauteren FHE

Level 4algorithm秘密共享与 MPC

这一课要解决什么

By the end, you can explain what “Brakerski-Fan-Vercauteren FHE” solves, which assumption it relies on, and at least one boundary where it fails.

Algorithm : Brakerski-Fan-Vercauteren FHE (BFV 全同态加密). BFV encodes plaintext as elements of a polynomial ring and carries them in noisy ring-LWE ciphertexts. Addition is direct; multiplication uses a tensor product followed by key switching and relinearisation to bring the ciphertext back to two components.…

为什么值得读

It turns “send data to the cloud, let the cloud compute without seeing plaintext” from a concept into engineering. BFV's integer semantics suit statistics, billing, database aggregation and fixed-point inference; compared with CKKS's approximate floating point, it fits tasks that demand exact results. Restate the chain as input → state → transform → output → criterion.…

边界与攻击面

BFV is not “run any program encrypted”. Multiplication depth is limited by the noise budget; modulus switching, key switching and relinearisation add noise; parameters that are too small invite lattice attacks, while large parameters are too slow. It does not hide access patterns, and decrypted outputs can leak information. Side channels and key management still matter. T K: M → C；T K^{-1}: C → M；…
