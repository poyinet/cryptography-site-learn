Algorithm : Hamming Quasi-Cyclic (HQC 备选 KEM). HQC is a code-based KEM. The public key hides the structure of a quasi-cyclic code. Encapsulation selects a controlled-weight error vector and computes ciphertext under the public key.…

为什么值得读

Post-quantum migration needs algorithm diversity. If lattices suffer a structural break, the ecosystem should not rest on one assumption. NIST selected HQC as a backup KEM in 2025 so the standard portfolio has a second independent path. Its keys and ciphertexts are larger, but its failure modes differ. 边界与攻击面

The main risks are decoding failure rate, weak keys, side channels and parameter choice. An observable decoding failure can leak information; timing and cache behaviour can also be exploited.
