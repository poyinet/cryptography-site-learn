为什么值得读

Trust rests on a pre-shared secret: §1 Network Security says "Transactions between the client and RADIUS server are authenticated through the use of a shared secret, which is never sent over the network." Authentication therefore does not rely on the channel.

边界与攻击面

The weak points are password hiding and MD5: §2 explains the password "is hidden using a method based on the RSA Message Digest Algorithm MD5 [3]." and §8 concedes "The User-Password hiding mechanism described in Section 5.2 has not been subjected to significant amounts of cryptanalysis in the published literature."
