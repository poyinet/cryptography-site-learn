HC-128

Level 3algorithmOTP 与流密码

这一课要解决什么

By the end, you can explain what “HC-128” solves, which assumption it relies on, and at least one boundary where it fails.

Algorithm : HC-128 (HC-128 流密码). Two secret tables of 512 words HC-128 takes a 128-bit key and a 128-bit IV and keeps two tables P and Q, each of 512 32-bit words: 32,768 bits, or 4 KiB. Each step updates one element of one table and reads from the other table through a nonlinear filter, emitting one 32-bit keystream word.…

为什么值得读

HC-128 is built for bulk software encryption: it runs on scalar 32-bit operations without AES instructions. The designer reports about 3.05 cycles per byte on a Pentium M, well ahead of table-driven software ciphers of its time. It is an eSTREAM software-portfolio member and is unpatented. The price is a 4 KiB state and a 1024-step initialization.…

边界与攻击面

Key/IV reuse is fatal: the same K and IV produce the same keystream, and two ciphertexts XOR to the XOR of the plaintexts. HC-128 has no built-in authentication, so the protocol must add integrity protection. The h1/h2 functions index P/Q with secret data, so software implementations expose key-dependent cache access patterns.…
