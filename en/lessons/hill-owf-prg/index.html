Håstad-Impagliazzo-Levin-Luby Theorem

Level 4theorem理论基础

这一课要解决什么

By the end, you can explain what “Håstad-Impagliazzo-Levin-Luby Theorem” solves, which assumption it relies on, and at least one boundary where it fails.

Theorem : Håstad-Impagliazzo-Levin-Luby Theorem (HILL 定理). OWF and PRG are equivalent The Håstad–Impagliazzo–Levin–Luby theorem: a pseudorandom generator exists if and only if a one-way function exists. PRG→OWF is direct: a generator that stretches a pseudorandom string is itself hard to invert. The hard direction is OWF→PRG.…

为什么值得读

It lifts the minimal assumption of cryptography (OWF) to its most-used resource (pseudorandomness). Stream ciphers, key derivation, salts, commitments and zero-knowledge randomness all trace back to a PRG; HILL says this needs no extra number-theoretic assumption.…

边界与攻击面

1. Asymptotic construction. HILL’s constants and polynomial degrees are enormous; it cannot be deployed directly. 2. It needs an OWF. If no OWF exists, the theorem gives nothing; it does not prove that OWFs exist. 3. Stretch is limited by computational entropy. The output cannot exceed the intermediate distribution’s computational entropy; hashing does not create entropy. 4. It needs a universal hash family.…
