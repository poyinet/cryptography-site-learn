ISO/IEC 9797-1 block-cipher MAC

Level 3standard消息认证与 AEAD

这一课要解决什么

By the end, you can explain what “ISO/IEC 9797-1 block-cipher MAC” solves, which assumption it relies on, and at least one boundary where it fails.

Standard : ISO/IEC 9797-1 block-cipher MAC (ISO/IEC 9797-1 分组密码 MAC). One model, six algorithms ISO/IEC 9797-1 does not define a single MAC; it defines a model for MACs based on an n-bit block cipher: key derivation, padding, splitting, initial transformation, iteration, final/output transformation and truncation.…

为什么值得读

A block-cipher MAC reuses existing AES/DES hardware and introduces no new hash; the CBC chain is simple and streamable, which suits financial messages, smart cards and protocol authentication. It bases message integrity and origin authentication on the same block-cipher assumption. Plain CBC-MAC is provably secure only for fixed-length messages.…

边界与攻击面

Annex B explicitly notes that Padding 1 can suffer trivial forgery; the CBC-MAC security proof assumes fixed-length messages. For variable-length messages, use a final-transform algorithm or CMAC, and never share the MAC key with encryption. An m-bit tag has forgery probability about 2^-m; a 32-bit tag is too short for high-speed networks.…
