为什么值得读

RFC 5794 说 ARIA 是 2003 年由韩国密码学家开发的通用分组密码，适合大多数 32 位和 8 位处理器上的软件和硬件实现；它 2004 年成为韩国标准分组密码（KS X 1213:2004），在韩国广泛使用，尤其是政府面向公众的服务，并在 2007 年被纳入 PKCS 11。韩国电子政务标准框架的开发指南在 标准化动向 一节也写明，ARIA 于 2004 年依据国家标准基本法被指定为国家标准，标准编号是 KS X 1213:2004。这与 RFC 5794 的叙述一致。RFC 5794 第 3 节说 ARIA 设计上能抵抗所有已知的分组密码攻击，并称比利时 K.U.Leuven 的 COSIC 组分析后没有发现安全缺陷。这是 2010 年 RFC 的评估，不是对全部攻击模型的形式化证明。

边界与攻击面

RFC 5794 的「resistant to all known attacks on block ciphers」（抵抗所有已知的分组密码攻击）和「no security flaw has been found」（未发现安全缺陷）是 2010 年文档中的设计者评估，不是对全部攻击模型的形式化证明，也不保证未来不会出现更好的分析方法。本文不把它们扩大成绝对安全结论，也不引用未经本文核实的攻击论文来宣称 ARIA 已被攻破。ARIA 的部署位置需要区分：它是韩国国家标准算法，在韩国政府面向公众的服务中有明确使用记录，并在 2007 年被纳入 PKCS 11；RFC 6209 为 TLS 1.2 定义 ARIA 套件，但该 RFC 是 Informational，TLS 1.3 没有 ARIA 套件。那是韩国的国家标准和 2007 年一次纳入 PKCS 11 的记录，不等于在所有最新协议中默认可用。…
