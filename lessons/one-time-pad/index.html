一次性密码本

层级 3termOTP 与流密码

这一课要解决什么

读完这一课，你能用自己的话解释「一次性密码本」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

术语 ：一次性密码本（One-Time Pad (OTP)）。定义句在 RFC 4949 的一次性密码该条目第二义里：「An encryption algorithm in which the key is a random sequence of symbols and each symbol is used for encryption only one time -- i.e., used to encrypt only one plaintext symbol and thus produce only one ciphertext symbol -- and a copy of the key is used similarly for de…

为什么值得读

为什么 一次性 这个条件值得单独命名，HAC 第一章在评估安全性的模型一节给出性质侧的定义：「Unconditional security for encryption systems is called perfect secrecy.For perfect secrecy, the uncertainty in the plaintext, after observing the ciphertext, must be equal to the a priori uncertainty about the plaintext」。同节接着把无条件安全的必要条件落在密钥长度上，并点名一次性密码本是该性质的一个例子——也就是说这个词命名的是用密钥材料换取无条件安全这条交换。

边界与攻击面

限度全在密钥一侧，且 HAC 第一章把两条都写在 1.5.4 节的同一段散文里。其一，只有随机选取且绝不重复使用的密钥串才让 Vernam 密码被称为一次性系统或一次性密码本；其二，一旦复用就有可乘之机——「If the key string is reused there are ways to attack the system.」原文接着给出的措辞是两段密文的冗余可能使分析可行，该条目不把它写成必然破译。同段还论证，实现一个不可破系统要求与消息等长的随机密钥，这使其实用性被限制在少数专门场景，并把莫斯科到华盛顿的通信线路作为例证记下。
