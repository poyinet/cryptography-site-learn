对称分组密码

层级 2domain对称分组密码

这一课要解决什么

读完这一课，你能用自己的话解释「对称分组密码」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

领域 ：对称分组密码（Symmetric Block Ciphers）。本概览采用手册的定义 1.26，整句印在 hac1.txt:510：「A block cipher is an encryption scheme which breaks up the plaintext messages to be transmitted into strings (called blocks) of a fixed length t over an alphabet A, and encrypts one block at a time.」（分组密码是这样一种加密方案：把要传输的明文消息切成字母表 A 上定长 t 的串（称为分组），并一次只加密一个分组）。…

为什么值得读

设计者自己采用的模型正是现代标准继承的那个。rijndael-design.txt:710 把分组密码写作置换族：首句的分组长与密钥长带下标，本抽取件把下标压到基线，故此处转述；被引用的紧随其后的那一无下标分句是 「This set contains a Boolean permutation for each value of the cipher key k.」（对密钥 k 的每一个取值，该集合包含一个布尔置换）。每个密钥对应一个置换——同一算法因而是许多个密码，而解密恰为逆置换。…

边界与攻击面

三条边界都由本章自己说出。第一条是穷举，定义在 hac1.txt:436：「An encryption scheme can be broken by trying all possible keys to see which one the communicating parties are using (assuming that the class of encryption functions is public knowledge).This is called an exhaustive search of the key space.」（假定加密函数类是公知的，一种加密方案可以靠试遍所有密钥、看哪一个是通信双方所用的而被破掉；这称为对密钥空间的穷举搜索）。同一行接着说密钥空间应大到让这条路在计算上不可行，而设计者的目标就是让它成为所能得到的最好攻击——这正是争论一个分组密码密钥长度时所依据的全部标准。…
