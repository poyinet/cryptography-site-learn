Shamir 门限秘密共享

层级 2algorithm秘密共享与 MPC

这一课要解决什么

读完这一课，你能用自己的话解释「Shamir 门限秘密共享」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

算法 ：Shamir 门限秘密共享（Shamir Secret Sharing）。Shamir 门限秘密共享（SSS）回答一个很朴素的问题： 一把密钥，怎么拆成 n 份，让其中任意 t 份能拼回来、少一份什么都看不出来？ 设秘密是 s （可以当成一个大整数，或者按字节拆开分别处理）： 1. 选一个大素数 p ，所有运算在 GF(p) 上做。2. 随机造一个 t−1 次多项式 f(x) = s + a₁x + a₂x² + … + a {t−1}x^{t−1} 。 常数项是秘密本身 ，其余系数 a₁ … a {t−1} 必须是 均匀随机 的。3. 发给 n 个人 ：第 i 个人拿到 x i = i 处的值 f(i) ，也就是一对 (x i, y i) 。…

为什么值得读

Shamir 共享解决的是密钥管理里最反直觉的那个问题：有时候最好的保管钥匙的办法，是把它拆开。 一份密钥放在保险柜里，保险柜就是一个单点故障：被撬开就全完，丢了就全完。拆成 3 份分给 3 个人之后： - 两个人的合谋也不够 （3-of-5 门限）。- 一个人离职、失踪、去世，体系不瘫痪 。- 审计有了抓手 。每一份的持有都是可追责的事件，而不是「某人有一把万能钥匙」。Shamir 在 1979 年那篇论文的结尾把政治学讲得很直白：「 我们可以让足够大的多数派获得采取行动的权威，同时让足够大的少数派握有否决权。 」这不是密码学论文里的比喻，这是字面意义上的分权制衡。 更根本的一点：这是密码学里极少数「不依赖任何困难问题」的构造。 RSA 靠大数分解，ECC 靠离散对数，AES 靠计算不可逆——这些的安全性都是 信念 。Shamir 共享的安全性是 定理 。…

边界与攻击面

Shamir 共享的数学没有弱点。但它在工程上失败的方式，多到值得列一张清单。 - 「分片」不等于「分散」 。最常见的失败：3-of-5 的五份分片，存在同一个云盘账号、同一个邮箱、同一台笔记本的同一个文件夹里。 这等于没拆 ——攻击者拿一份就够了。Shamir 保护的是「集合的数学性质」，它不会替你把文件分散到五个国家。- 分片自己会泄密 。每份分片是一对 (x i, y i) 。 把五份分片放在同一个文档里，等于把私钥交出去 ——任何一个人都能拼。备份流程里，「先写到 U 盘再分发给五个人」这一步，往往在分发之前就已经泄漏了。- 出题人（dealer）必须诚实 。原始 Shamir 方案假设出题人不会给不同的人不同的多项式。 一个恶意的出题人可以发一份「有偏」的分享 ——共享本身数学上完美，但拼出来的秘密是错的，而且只有到恢复时才会发现。这正是 可验证秘密共享（VSS） 存在的理由。…
