Dual_EC_DRBG 后门曝光

层级 2event随机数与 CSPRNG

这一课要解决什么

读完这一课，你能用自己的话解释「Dual_EC_DRBG 后门曝光」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

事件 ：Dual EC DRBG 后门曝光（Dual EC DRBG Backdoor Revealed）。Dual EC DRBG 用一对椭圆曲线点 P、Q 生成随机比特：内部状态乘以 P，取 x 坐标的截断值输出。标准没有解释 P、Q 的来源。如果 Q = d·P 且某人知道 d，就能从输出恢复内部状态并预测后续比特。后门不在算法公式里，而在参数之间的秘密关系里。

为什么值得读

它把“随机数”从背景设施变成安全叙事的中心。TLS、VPN、磁盘加密都依赖 CSPRNG；随机源一旦可预测，密钥、盐和会话令牌都会崩塌。这起事件也是公开密码学审查的转折点：参数生成过程必须可复现、可解释，不能只说“相信我们”。

边界与攻击面

攻击者是知道 Q 与 P 秘密关系的一方，不需要破解椭圆曲线离散对数。2013 年 Snowden 文件引发的报道称 NSA 可能持有该关系，但公开证据主要证明“结构上可行”，并未逐条证明所有部署都被利用。NIST 随后移除该算法，并强调参数可复现生成。
