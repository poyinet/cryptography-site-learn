密码模块安全要求（FIPS 140-3）

层级 2standard密钥管理

这一课要解决什么

读完这一课，你能用自己的话解释「密码模块安全要求（FIPS 140-3）」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

标准 ：密码模块安全要求（FIPS 140-3）（Security Requirements for Cryptographic Modules (FIPS 140-3)）。FIPS 140-3 的自我定位写在说明一节：「This standard specifies the security requirements that will be satisfied by a cryptographic module utilized within a security system protecting sensitive but unclassified information」，并把分级方式一次讲清——「The standard provides …

为什么值得读

为什么要一份模块标准：算法正确不代表实现安全，所以要求覆盖设计与运行的整条链。摘要列出范围：「These areas include cryptographic module specification; cryptographic module interfaces; roles, services, and authentication; software/firmware security; operating environment; physical security; non-invasive security; sensitive security parameter management; self-tests; life-cycle assurance; and mitigation of other attacks.」

边界与攻击面

限度有两处可读出来。其一，它是联邦采购与验证口径，标准把用途限定在「a security system protecting sensitive but unclassified information」；§6 另给两条出路——「Cryptographic modules that have been approved for classified use may be used in lieu of modules that have been validated against this standard.」与「The adoption and use of this standard is available to private and commercial organizations.」。…
