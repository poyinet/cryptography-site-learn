炸弹机

层级 3machine破译方法 · 转子/机械密码

这一课要解决什么

读完这一课，你能用自己的话解释「炸弹机」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

机器 ：炸弹机（Bombe）。 Enigma 的路径 Enigma 的加密路径可写成 c = S(R j(S(p)))，其中 p 是明文键位，S 是插线板对合（S(S(x))=x），R j 是转子组在位置 j 的替换。反射器使路径 reciprocal：同一位置下，p 与 c 的关系对称。对一段 crib，已知 p j 与 c j，得到一组未知插线板约束。 菜单与转子假设 把 crib 中每个位置的字母关系画成图：节点是字母，边是“在该位置经过转子后相连”的约束。一个菜单可以包含多个闭环；闭环越多，约束越强。炸弹机固定一个转子顺序，枚举起始位置；对每个假设，它把菜单中的字母接成电路，并让电流沿转子路径传播。…

为什么值得读

Enigma 的密钥空间包括转子顺序、起始位置和插线板。直接枚举插线板不可行。炸弹机利用已知 crib 把问题变成“在一个转子假设下，菜单约束是否电气一致”，把大量插线板自由度消去，只留下少量 stop。 为什么需要对角线板 没有对角线板时，菜单必须靠闭环产生足够约束，短 crib 或不带环的菜单会产生大量假 stop。对角线板利用 stecker 的 reciprocal 性质，把单向约束变成双向传播，让更多菜单可用。 对机械计算的意义 炸弹机是专用约束求解器：它不执行通用程序，也不存储消息，只用电路并行检查假设。它展示了“用物理结构实现逻辑推导”的工程路线，与后来的电子计算机不同。

边界与攻击面

1.需要已知或高度可信的 crib；crib 错误会生成错误菜单。2.需要正确的转子 wiring、反射器和机器型号；型号变化会改变路径。3.菜单闭环不足时假 stop 增多；对角线板能缓解但不能消除。4.转子顺序与起始位置的搜索仍很大；四转子海军 Enigma 增加复杂度。5.它不直接恢复插线板，也不直接输出明文；stop 必须由人工验证和补全。6.它不是通用计算机，不能执行任意算法；对非 Enigma 或强改装方案不适用。炸弹机是特定历史条件下的专用密码分析机。它的“计算”是电路约束传播，不是现代意义上的可编程计算；把它描述成“第一台计算机”或“自动破解所有 Enigma”都不准确。
