Rabin 陷门公钥密码

层级 3algorithm非对称公钥

这一课要解决什么

读完这一课，你能用自己的话解释「Rabin 陷门公钥密码」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

算法 ：Rabin 陷门公钥密码（Rabin Cryptosystem）。 二次剩余陷门 Rabin 签名把消息哈希映射到模 n 的二次剩余，签名是方程 x²+bx≡H(m,u) 的一个根。公钥是 n=pq 与常数 b；私钥 p,q 用于在 Z p、Z q 上开方，再用 CRT 合并。 四根与编码 平方映射的每个值有四个根；签名者只公开一个，两个不同根会泄露 gcd 从而分解 n。标准化变体用 Rabin-Williams 编码和冗余，并把随机串 u 纳入哈希，避免根选择歧义和选择消息攻击。 安全归约 在随机预言机模型下，伪造签名可归约为求模 n 平方根，而求平方根与分解 n 等价。验证只需一次模平方和编码检查，比 RSA 的模幂快数百倍。

为什么值得读

Rabin 是第一个可证明“伪造难度等价于分解大整数”的实用签名族。RSA 只做到“破签不比分解更难”，Rabin 给出反向归约：能从伪造推出因子。验签一次平方，签名端一次开方加 CRT，计算量都低于同规模 RSA；这让它适合智能卡、传感器和低功耗验证方。代价是签名端要处理四根与编码，工程上比 RSA 难用，标准化版本转向 Rabin-Williams。

边界与攻击面

裸平方根签名对选择消息攻击脆弱：攻击者取随机 x，请求签 x² mod n；若返回的根不是 ±x，gcd(x−s,n) 直接给出 p 或 q。必须用带冗余的编码和随机化哈希阻断。ISO 9796-2 的 Rabin-Williams 实例曾被 Coron–Naccache–Stern 类攻击和后续改进攻击；哈希太短或编码不当会允许伪造。参数、编码和根的选择都必须按标准执行。
