恩尼格玛 Enigma

层级 3machine转子/机械密码

这一课要解决什么

读完这一课，你能用自己的话解释「恩尼格玛 Enigma」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

机器 ：恩尼格玛 Enigma（Enigma）。恩尼格玛不是一台固定规格的机器，而是一系列机电密码机。不同型号的转子数量、接线、反射器、步进规则和是否带接线板都不完全相同。本文以德国陆军和空军使用的 Enigma I 为主要实例：它有三个可更换转子、一个反射器和一块接线板。海军后来使用的 M4 有四个转子，不能把 M4 的接线和 Enigma I 混为一谈。Enigma I 的电流路径是：按键 → 接线板（Steckerbrett）→ 入口盘（ETW）→ 右转子 → 中转子 → 左转子 → 反射器（UKW）→ 左转子 → 中转子 → 右转子 → 接线板 → 灯泡。…

为什么值得读

恩尼格玛展示了状态随时间变化的替换：同一个字母在连续按键中可能被不同的映射加密，因此它不是单表替换。它的强度来自转子接线、步进、环设置、起始位置和接线板的组合，而不是某一根线或某一个齿轮。它也让算法之外的系统变得具体。机器只是硬件；双方还必须共享转子顺序、环设置、起始位置和接线板，遵循消息密钥程序，并防止操作错误。任何一环出错，都可能让分析者获得比暴力搜索更好的入口。反射器是一个典型的工程折中：它让加密和解密使用同一套设置，简化了操作，但也保证字母不会加密成自身，并给分析者提供了可排除的明文猜测。这个结构在当时被视为简化操作的设计选择；后来的分析指出它也带来结构性弱点，不能从事后视角断言设计者已经预见了所有后果。

边界与攻击面

反射器把每个字母送到另一个字母，再沿原路返回，因此任何状态下 E(x)≠x。攻击者可以用这一点排除 crib（猜测明文）与密文中同一位置相同的对齐。单凭这一点不足以「break Enigma」（破解恩尼格玛），但显著缩小了候选。 步进有规律 右转子每次按键都走，中转子在特定缺口位置走，左转子更少走。双重步进虽然让序列比里程表复杂，但仍然是由机械规则决定的。分析者可以枚举 60 种转子顺序和 17,576 个起始位置；考虑双重步进后，可达设置像集为 16,926，周期为 16,900。分析者不必枚举接线板。 操作程序会泄露结构 重复使用消息密钥、选择可预测的起始位置、固定格式的电报开头、操作员习惯，都可能给分析者提供已知明文或候选对齐。历史上的破译不是猜出整台机器的密钥，而是把程序弱点、crib、数学结构和机器辅助结合起来。…
