GCM 与 GMAC 模式

层级 3standard消息认证与 AEAD

这一课要解决什么

读完这一课，你能用自己的话解释「GCM 与 GMAC 模式」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

标准 ：GCM 与 GMAC 模式（Galois/Counter Mode and GMAC）。文件标题即定义：「NIST Special Publication 800-38D Recommendation for Block Cipher Modes of Operation: Galois/Counter Mode (GCM) and GMAC」，作者 Morris Dworkin，日期行「November 2007」。它把 GCM 与 GMAC 一并规范化：前者是加密+认证的模式，后者是只产出认证码的用法。

为什么值得读

它解决的是 加密又要认证又要可验证 的合并需求：文件给出 GCM 与 GMAC 两种用法，并把唯一性要求单列一节——§8 名为「Uniqueness Requirement on IVs and Keys」。§2 只把符合性放在 CMVP 框架里，未提及其它验证计划。

边界与攻击面

限度一是那条 几乎完全失效 的警告，但它是有条件的：原文写「a breach of the requirement in Sec.8 for the uniqueness of the initialization strings may compromise the security assurance almost entirely」，并结论式建议「this mode of operation should not be deployed unless compliance with this uniqueness requirement is ensured」。限度二是文件其实两边都谈：8.1 节标题就是 Key Establishment，指向 TLS、IKE v1/v2 与 SSH 的密钥导出函数；8.2 节标题是 IV Constructions，给出确定式与基于随机数生成器两种构造。…
