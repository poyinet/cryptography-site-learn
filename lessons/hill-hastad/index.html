Håstad 广播攻击

层级 4theorem破译方法

这一课要解决什么

读完这一课，你能用自己的话解释「Håstad 广播攻击」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

定理 ：Håstad 广播攻击（Håstad's Broadcast Attack）。 同一消息广播到多个模数 设消息 m 用同一小指数 e 分别加密给 k 个接收者，模数为两两互素的 N1,…,Nk： c i = m^e mod N i。若 k ≥ e 且 m^e < ∏ N i，由中国剩余定理可把这些同余式合成 C ≡ m^e (mod ∏ N i)，且 0 ≤ C < ∏ N i。因为 m^e 也小于乘积，C 就等于整数 m^e，而不是“模意义下”的幂；对 C 取整数 e 次根即得 m。…

为什么值得读

e=3 的 RSA 加密很快，适合资源受限设备；但把同一条消息广播给三个以上接收者，且不做随机化填充，等于把 m^3 放到一个比 m^3 更大的整数环里，攻击者可以用 CRT 精确重建它。Håstad 的一般化说明，即使每条消息不同，只要它们按已知仿射关系变化，足够多的接收者仍会泄露消息。 为什么随机化填充能挡住 OAEP 等随机化填充让每条消息的编码包含独立随机数，接收者之间的编码不再满足同一个低次多项式。此时 CRT 合成的是不同随机多项式的密文，整数开根不再对应明文。注意“加了填充”不等于“安全”：确定性填充、固定时间戳或可预测计数器仍可能保留关系。 现实判断 评估广播协议时，先问：是否同一消息？e 是 3 还是 65537？接收者数量是否达到 e？是否每条都独立随机化？模数是否两两互素？这些问题比“RSA 是否 2048 位”更直接。

边界与攻击面

1.接收者少于阈值。基本攻击需要 k≥e；一般仿射定理需要 k e(e+1)/2。少一个接收者就可能失败。2.m^e 不小于乘积。此时 CRT 得到的 C 只是 m^e mod 乘积，整数开根不再等于 m；需要格方法或其他信息。3.模数不两两互素。CRT 条件破坏；不过这时 gcd 可能直接给出分解，是另一种攻击。4.随机化填充。每条消息的编码不同，低次关系不成立。5.e 很大。阈值和多项式次数随 e 增长；e=65537 时一般仿射攻击的接收者数量不现实。6.消息不是仿射相关。Håstad 的定理要求已知低次多项式；任意关系不保证可解。
