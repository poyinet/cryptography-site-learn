IND-CCA2 与非延展性等价

层级 4theorem理论基础

这一课要解决什么

读完这一课，你能用自己的话解释「IND-CCA2 与非延展性等价」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

定理 ：IND-CCA2 与非延展性等价（IND-CCA2 equivalence with non-malleability）。 两个游戏 IND-CCA2：挑战者生成 pk/sk，给对手 A 解密 oracle；A 选两个等长消息 m0、m1，拿到 y = E(mb)，仍可继续问解密 oracle，但不能问 y；A 猜 b，优势可忽略则安全。NM-CCA2：A 拿到 y 后输出一组不同于 y 的密文 y'，并给一个关系 R；若 y' 解密出的明文与挑战明文“有意义相关”（例如 x' = x + 1）的概率显著高于随机，则攻破。 六个概念 把目标 {IND, NM} 与攻击 {CPA, CCA1, CCA2} 组合，得到六个定义。…

为什么值得读

证明是归约：给 NM-CCA2 对手 B 构造 IND-CCA2 对手 A。B 输出 y' 后，A 用 CCA2 解密 oracle 解出 x'，检查 R(x b, x')；如果 B 能以不可忽略优势把 x b 与相关明文联系起来，A 就能以约一半优势猜 b。CCA2 的关键是挑战后仍能解密 y'，CCA1 做不到。 为什么重要 IND-CCA2 是公钥加密最强的实用保密性定义，同时排除“拿到密文就能造出相关密文”的延展攻击。Cramer–Shoup、RSA-OAEP（在随机预言机与 Fujisaki–Okamoto 转换下）等方案按此定义证明；只要证明 IND-CCA2，就自动得到 NM-CCA2，不必单独证非延展性。

边界与攻击面

渐近定义忽略具体参数、密钥生成缺陷、侧信道和实现错误；Bleichenbacher 对 PKCS 1 v1.5 的攻击说明“看起来能加密”不等于 CCA2 安全。证明还依赖计算假设，例如 DDH、CDH 或 RSA。NM 有 simulation-based 与 comparison-based 两种定义；Bellare 等的等价是对其 comparison-based 定义，该定义与 Dolev–Dwork–Naor 的 simulation 定义等价。CCA2 下等价，不代表 CPA/CCA1 也有同样关系。 随机预言机 OAEP 的 CCA2 证明在随机预言机模型；标准模型下的高效方案更少。定义本身不保证存在高效构造，也不保证在量子模型下成立。
