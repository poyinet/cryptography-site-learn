MD5 散列

层级 2algorithm哈希

这一课要解决什么

读完这一课，你能用自己的话解释「MD5 散列」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

算法 ：MD5 散列（MD5）。MD5 是 Ronald L.Rivest 设计的消息摘要算法，由 RFC 1321（1992 年 4 月）描述：输入任意长度的消息（位数 b 可以是 0、「need not be a multiple of eight, and」不必是 8 的倍数、也可以任意大；本副本把该短语断在两行上），输出固定的 128 位（16 字节）"fingerprint"（指纹）或"message digest"（消息摘要）。…

为什么值得读

RFC 1321 §1 与 §4 给出了 MD5 的设计取向，几乎逐条可以对照 MD4 读： - 32 位机器上的速度 ：原文 "The MD5 algorithm is designed to be quite fast on 32-bit machines"，并且 "does not require any large substitution tables"，"can be coded quite compactly"（设计为在 32 位机器上相当快，不需要任何大的替换表，可实现得相当紧凑）。每 512 位块 64 次操作，每次只有若干次模 2^32 加法、一条按位函数、一条循环左移，全部落在 32 位通用指令上。- 对 MD4 的退让 ：RFC 明确说 MD5 是 MD4 的扩展，比 MD4 稍慢但设计上更 "conservative"。…

边界与攻击面

MD5 的破译是分层的，RFC 6151 §2.1 给出了权威时间线：1993 年 den Boer 与 Bosselaers 描述了压缩函数的伪碰撞；1996 年 Dobbertin 原文："demonstrated a collision pair for the MD5 compression function with a chosen initial value"（展示了 MD5 压缩函数在选定初值下的一对碰撞）；王小云、冯登国、Xuejia Lai、余洪波 2004 年的论文第一次给出 MD5 的两对碰撞；2005 年 EUROCRYPT 上王小云与余洪波的论文公布了详细攻击技术。…
