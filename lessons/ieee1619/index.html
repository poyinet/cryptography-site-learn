IEEE 1619 XTS-AES 存储加密

层级 3standard对称分组密码

这一课要解决什么

读完这一课，你能用自己的话解释「IEEE 1619 XTS-AES 存储加密」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

标准 ：IEEE 1619 XTS-AES 存储加密（IEEE 1619 XTS-AES storage encryption）。 XEX：先异或 tweak，再 AES，再异或 XTS-AES 是 XEX（XOR–Encrypt–XOR）的实例。对数据单元 i 内的第 j 个块 P j，令 T j = E {K2}(i) ⊗ α^j，其中乘法在 GF(2^128)、α 是本原元；加密为 C j = E {K1}(P j ⊕ T j) ⊕ T j，解密反过来。相同的明文在不同扇区或不同块位置会得到不同密文；同一位置重写则得到相同密文。 两个密钥 XTS 的密钥是 K1 K2，K1 加密数据，K2 只生成 tweak。…

为什么值得读

存储设备按扇区随机读写，不能像 CBC 那样依赖整个文件的链式状态。XTS 的每个块可以独立解密，tweak 由扇区号/LBA 和块号隐式算出，不需要把 IV 或 nonce 存进磁盘；密文不扩张，适合原地加密。 比 ECB 强在哪 ECB 下相同明文块产生相同密文，泄露扇区结构；XTS 用地址相关的 tweak 打散相同块。它不是认证加密，不能防篡改，但比纯 ECB/CBC 更适合磁盘的随机访问模型。

边界与攻击面

XTS 没有认证标签，攻击者可以重放、重排、篡改密文块；若攻击者能观察到明文–密文对并改写，可能操控解密结果。必须在文件系统或应用层加完整性（AEAD、HMAC、Merkle 树），或把 XTS 当作“防离线窃取”而不是“防主动篡改”。K1/K2 必须独立；同一 key scope 的块数要受限。2025 标准把 key scope 限到 2^36–2^44 块，按 2^128 生日界估算，碰撞概率约 2^-56 到 2^-40。扇区号必须唯一且不可重用；克隆、快照、磁盘重映射都要保证 tweak 不复用。 不是传输加密 XTS 面向块存储，不适合 TLS 或网络传输；传输层应使用 AEAD。
