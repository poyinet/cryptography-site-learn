伪随机函数

层级 3termOTP 与流密码

这一课要解决什么

读完这一课，你能用自己的话解释「伪随机函数」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

术语 ：伪随机函数（Pseudorandom Function (PRF)）。伪随机函数是一个密钥化函数，敌手无法区分它与真正随机函数。它是 PRF 安全模型的核心对象，HMAC、CMAC 和分组密码都可作为 PRF 候选；PRF 不等于可逆分组密码。

为什么值得读

该条目单列，是因为它把OTP 与流密码中的术语落到可核证据：有可指认的参与者、可复算的步骤，或有馆藏、档案、标准编号支撑的实物与文本。相邻条目只用于定位，不并入该条目，也不替别条作证明。

边界与攻击面

PRF 安全依赖种子保密和具体构造；CMAC 作为 PRF 时需防密钥控制。上位概念说明它属于哪一类；区别特征说明它与相邻术语的差异；边界说明哪些对象不属于它。正例必须落在外延内，反例必须刚好跨过边界；只给一个同义词不算定义。
