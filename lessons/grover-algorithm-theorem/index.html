格罗弗算法

层级 4theorem量子密码

这一课要解决什么

读完这一课，你能用自己的话解释「格罗弗算法」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

定理 ：格罗弗算法（Grover's Algorithm）。 定理（格罗弗 1996 + BBBV 1997 + Zalka 1997）：在 N 个候选里找一个满足条件的项，量子算法需要 Θ(√N) 次查询，而且这已经是极限。 问题设定极简：N 条无序记录，其中恰好一条满足谓词 f，找出它。 上界（格罗弗 1996） ：存在一个量子算法，用 O(√N) 次 f 求值找到那个"标记项"，成功率可以做到任意接近 1。具体是 π/4·√N 次迭代，成功率约 1 − 1/N。 下界（BBBV 1997） ：任何量子算法，无论怎么设计，若只能通过查询 f 来获取信息，至少需要 Ω(√N) 次查询。 注意量词：这是对所有量子算法、所有 f、所有成功概率要求成立的。…

为什么值得读

因为它砍掉的只是指数的一半，而且下界证明告诉你这就是地板。量子威胁的完整叙事，必须由肖尔和格罗弗两条定理合起来才讲得完。 - 公钥密码：断崖。 肖尔把分解和离散对数从指数级压到多项式级——不是慢一点，是 归零 。RSA、ECC 一起完蛋。- 对称密码：台阶。 格罗弗把 2^n 砍到 2^(n/2)—— 只是砍半 ，而且下界证明说这就是极限。所以"量子计算机来了会怎样"的完整答案是： 公钥密码必须换，对称密码必须加长位。 这解释了后量子密码迁移里所有看似奇怪的选择：为什么 NIST 不推荐任何低于 128 位经典强度的对称算法？为什么 ML-KEM-768 是 192 位经典、128 位量子？——因为 公共部分必须扛住肖尔，私密部分只需要扛住格罗弗 。格罗弗更深一层的意义是它给了 可规划性 。"128 位密钥将来不够用"这句话，从猜测变成了定理；而定理是可以排期的。…

边界与攻击面

格罗弗算法的攻击面不在数学里，在物理里。 - 深度才是杀手，不是量子比特数。 Grassl 等人 2016 年的资源估算：破 AES-128 约需 2953 个逻辑量子比特 ，但 T 深度约 2^80 ；AES-192 是 4449 个逻辑比特、T 深度 2^112；AES-256 是 6681 个逻辑比特、T 深度 2^144。 量子比特数量看着不多，顺序步数是 2^80 量级 ——那是 10^24 次纠错门操作。- 哈希原像更狠。 Amy 等人 2016 年的估算：Grover 找 SHA-256 原像只需约 2^12.6（≈6200）个逻辑量子比特，却要跑约 2^153.8 个表面码周期 。 原像搜索是"便宜在比特、贵在时间"；密钥搜索则是"比特和时间都贵"。 - 不能靠堆机器。 Zalka 证明量子搜索无法获得比"把空间切给独立量子计算机"更好的并行化。 经典暴力破解可以线性加机器，格罗弗不行。…
