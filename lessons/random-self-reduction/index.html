随机自归约

层级 4theorem理论基础

这一课要解决什么

读完这一课，你能用自己的话解释「随机自归约」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

定理 ：随机自归约（Random Self-Reducibility）。 把最坏实例随机化 设 f 是单向函数。若存在多项式时间算法 R，对任意 x 采样 r，输出 y=R(x;r)，使 y 的分布与 x 无关（通常接近均匀），并且给定 f(y) 与 r 可在多项式时间恢复 f(x)，则称 f 随机自归约。于是：只要 f 在平均随机实例上难，f 在每个实例上都难。 离散对数 在阶为 q 的循环群 G 中，g 是生成元，y=g^x。取 r←Z q，计算 y' = y·g^r = g^{x+r}。若 oracle A 能求 y' 的离散对数 x'，则 x = x'−r mod q。y' 在 G 中均匀分布，与 y 无关；一次随机实例的答案就还原了原实例。…

为什么值得读

密码学假设通常说“没有多项式算法能在最坏实例上求逆”；实际攻击者只需要在随机实例上成功。随机自归约把这两个世界连起来：平均实例上的成功可以搬到任意实例，反之最坏实例的困难会扩散到随机实例。 为什么 RSA 实现需要盲化 盲化不仅隐藏消息，也让解密时间与密文无关：每次解密先乘随机 r^e，再在最后除掉 r。侧信道攻击者看到的中间值与真实 m 无关；这是随机自归约在工程中的直接用法。

边界与攻击面

1.需要代数结构。随机化必须保持问题实例的同态关系；任意单向函数、散列函数没有这种结构。2.需要可逆盲化因子。RSA 的 r 必须在 Z N^ 中；若 r 与 N 不互素，逆不存在，盲化失败。3.oracle 的成功率是平均的。若 oracle 只在某些随机实例上成功，重复采样可以把成功概率放大，但需要独立性或足够好的分布。4.不自动给出具体安全界。盲化隐藏了中间值，但不证明 RSA 本身安全；它把攻击面从“任意实例”移到“随机实例”。5.群阶与表示要对。离散对数在复合阶群、椭圆曲线群中的随机化形式不同；公式要按群运算重写。 不是“随机化就能安全” 随机自归约是归约工具，不是防御本身。若底层问题在随机实例上也可解，盲化只增加常数开销，不改变可破性。
