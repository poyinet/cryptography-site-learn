线性同余发生器

层级 1algorithm随机数与 CSPRNG

这一课要解决什么

读完这一课，你能用自己的话解释「线性同余发生器」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

算法 ：线性同余发生器（Linear Congruential Generator）。线性同余发生器（LCG）是密码学史上最重要、也最被误用的一个算法。 它只有一行公式： X(n+1) = (a · X(n) + c) mod m 三个参数加一个种子： m 是模数， a 是乘子， c 是增量， X(0) 是种子。 输出就是状态本身 （或者状态的某几位）。就这么简单。它能成为半个世纪的标准答案，靠的是三个优点： 快 （一次乘加一次取模）、 可移植 （任何语言三行代码实现）、 周期可以做到和模数一样长 。…

为什么值得读

LCG 不是密码学的东西，但它是一个了不起的工程产物。 搞清楚它为什么成功、以及为什么不能用在密码学上，是理解现代密码学「什么才算安全」的最快路径。- 极快。 现代 CPU 上一次 LCG 只要几纳秒，比哈希快一个数量级。做蒙特卡洛模拟、负载均衡抖动、图形着色器里的噪声， 没有比它更划算的方案 。- 状态小。 状态就是一个 32 位或 64 位整数， 可以塞进一个寄存器 ，也可以塞进缓存行里避免原子操作。- 统计性质可分析。 周期、相关性、格结构都有理论刻画。 这在模拟领域是优点，在密码学领域是致命伤——因为「可分析」就意味着「可预测」。 - 一条直线。 没有任何分支、没有任何查表、没有任何异常情况。 它是密码学里最容易审计的算法之一——正因如此，它才成了攻击者的教科书目标。 它在密码学里失败的原因，恰好是它在模拟里成功的原因： LCG 的输出序列在数学上是一条 格（lattice） 。…

边界与攻击面

LCG 不是「被攻破」的，它是「一直被看穿」的。这份清单里每一条都是常识，但每年都有人重新踩一遍。 - 低位周期极短 ：对 m = 2^n 的 LCG，第 k 位低位的周期 最多是 2^(k+1) 。 最低位的周期就是 2 ——它在 0 和 1 之间来回摆。 任何还在用低位输出的代码，等于在输出一个计数器。 - 模 2^n 是 LCG 的天敌 ：模数是 2 的幂时，输出序列的 格结构特别难看 ，多维格上能直接看到平面。Knuth 的 谱检验（spectral test） 就是专门用来量这件事的， 一个参数选得不好的 LCG 在谱检验下会立刻露馅 。用素数模数（如 2^31−1 ）或精心挑选的 64 位乘子能缓解可见结构，但 消不掉根本的线性 。- 状态恢复攻击 ： - 输出即状态 → 一个输出就够 。- 截断输出（只给高位）→ 变成 隐数问题（Hidden Number Problem） ，用 格归约（LLL） 解。…
