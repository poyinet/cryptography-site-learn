格密码

层级 3term后量子 · 非对称公钥

这一课要解决什么

读完这一课，你能用自己的话解释「格密码」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

术语 ：格密码（Lattice-based Cryptography）。FIPS 203 定义 KEM 为「a cryptographic scheme that, under certain conditions, can be used to establish a shared secret key between two communicating parties」，由 KeyGen、Encaps 与确定性 Decaps 三个算法组成，并说明「The security of ML-KEM is based on the presumed hardness of the so-called Module Learning with Errors …

为什么值得读

标准先把底层公钥加密 K-PKE 经 Fujisaki-Okamoto 变换转成 KEM，并说明「ML-KEM is believed to satisfy so-called IND-CCA2 security」；同时警告「The scheme K-PKE is not IND-CCA2-secure and shall not be used as a stand-alone scheme」。Announcement 的 §10 记录「ML-KEM is the name given to the algorithm in this standard derived from CRYSTALS-KYBER」。

边界与攻击面

标准要求解密前的输入检查与「Destruction of intermediate values」。若密文解密校验不通过，算法执行 implicit rejection：原文该步那句在本副本里把 k、c、z 三个变量印成了丢失的数学字形，因此只转述不复引——k 的值改为 c 与存于 ML-KEM 私钥中的随机值 z 的哈希；并且那个秘密标志位「returning the value of the flag as an output in any form is not permitted」。表 1 给出三组参数约 2 的负 138.8、164.8、174.8 次方的解密失败率。
