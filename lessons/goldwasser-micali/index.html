Goldwasser-Micali 概率加密

层级 4theorem非对称公钥

这一课要解决什么

读完这一课，你能用自己的话解释「Goldwasser-Micali 概率加密」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

定理 ：Goldwasser-Micali 概率加密（Goldwasser-Micali Probabilistic Encryption）。 逐位加密 Goldwasser–Micali（GM）每次只加密一个比特。公钥是 (N,x) ，其中 N=pq ， x 是模 N 的二次非剩余；私钥是 p,q 。加密比特 m i 时选随机 y ，计算 c i=y²·x^{m i} mod N ：比特 0 得到二次剩余，比特 1 得到非剩余。 解密与同态 持有 p,q 的一方可判断 c i 是否为模 N 的二次剩余，从而恢复比特。两个密文相乘对应两个比特的异或： E(b1)·E(b2)=E(b1⊕b2) 。它因此是 XOR 同态的，但不是加法同态。…

为什么值得读

GM 回答了“公钥加密到底应该安全到什么程度”。在它之前，人们常以“不能恢复明文”作为标准；GM 提出语义安全：给定密文，攻击者猜不出明文的任何函数，优于直接猜。它的第二个贡献是概率加密：同一比特每次加密都不同，避免攻击者用候选明文重新加密来比对。现代 IND-CPA 定义就沿着这条线发展。

边界与攻击面

GM 每加密一个比特，密文约 N 位；加密一段消息会产生数百倍膨胀，速度也慢。它只支持 XOR 同态，不能做普通加法或乘法。原方案不是 IND-CCA2 安全的；工程实现还要保证 x 确实是二次非剩余、 N 是两个大素数之积，并且随机数 y 与 N 互素。实际系统不会用它替代 AES 或 RSA-OAEP。
