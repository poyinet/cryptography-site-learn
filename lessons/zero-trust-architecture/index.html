零信任架构

层级 3term协议与 PKI · 应用安全工程

这一课要解决什么

读完这一课，你能用自己的话解释「零信任架构」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

术语 ：零信任架构（Zero Trust Architecture）。SP 800-207 摘要把零信任定义为「an evolving set of cybersecurity paradigms that move defenses from static, network-based perimeters to focus on users, assets, and resources」，§2 进一步说明它是「a cybersecurity paradigm focused on resource protection and the premise that trust is never granted implicitly but must b…

为什么值得读

§2.1 列出七条基本信条：把所有数据源与计算服务视为资源；所有通信无论位置都受保护；对单个资源的访问按每次会话授予；访问由动态策略决定；企业持续度量自有与相关资产的完整性与安全态势；认证与授权动态且严格先行；并尽可能收集资产、网络与通信的当前状态信息用于改进防护。§2.2 的第一条假设是「The entire enterprise private network is not considered an implicit trust zone」。

边界与攻击面

§1 明确「ZT is not a single architecture but a set of guiding principles for workflow, system design and operations」，附录 B 也写明「there is no single solution that provides all the necessary components」。落地受现实约束：§7 说实施 ZTA 是「a journey rather than a wholesale replacement of infrastructure or processes」，§7.2 指出几乎没有企业能在一次技术更新中完成迁移。§5.4 还提醒相当多流量对第三层分析工具「opaque」，无法深度包检查的企业必须使用其他手段。
