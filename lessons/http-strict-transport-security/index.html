HSTS 强制 HTTPS

层级 3term协议与 PKI

这一课要解决什么

读完这一课，你能用自己的话解释「HSTS 强制 HTTPS」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

术语 ：HSTS 强制 HTTPS（HTTP Strict Transport Security (HSTS)）。HSTS 策略让符合规范的用户代理在访问 HSTS Host 前把不安全 URI 引用转换为安全引用。

为什么值得读

HSTS 应对被动网络攻击者、主动网络攻击者和不完善的 Web 开发者。

边界与攻击面

RFC 6797 明确 HSTS 不解决钓鱼和恶意软件；它覆盖 HSTS Host 及其 includeSubDomains 子域。上位概念说明它属于哪一类；区别特征说明它与相邻术语的差异；边界说明哪些对象不属于它。正例必须落在外延内，反例必须刚好跨过边界；只给一个同义词不算定义。
