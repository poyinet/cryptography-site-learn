密钥派生函数

层级 3term密钥管理

这一课要解决什么

读完这一课，你能用自己的话解释「密钥派生函数」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

术语 ：密钥派生函数（Key Derivation Function (KDF)）。密钥派生函数从一个主密钥或口令派生多个用途分离的子密钥。它应使用带盐、带上下文标签的 PRF（如 HKDF、PBKDF2、Argon2），避免同一密钥跨协议复用。

为什么值得读

KDF 从已有密钥派生额外密钥，因为通常需要更多密钥。

边界与攻击面

KDF 的安全性依赖底层 PRF 和输入密钥的保密性；CMAC 作为 PRF 时，本建议提供缓解措施以防止密钥控制。上位概念说明它属于哪一类；区别特征说明它与相邻术语的差异；边界说明哪些对象不属于它。正例必须落在外延内，反例必须刚好跨过边界；只给一个同义词不算定义。
