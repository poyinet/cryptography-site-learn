算法 ：CLEFIA 轻量级分组密码（CLEFIA）。CLEFIA 是 128 位分组密码，密钥长度为 128、192 或 256 位，分别使用 18、22、26 轮。它采用 4 分支广义 Feistel 网络（GFN4），接口与 AES 兼容：固定 128 位块，三种密钥长度。数据随机化部分把 128 位明文分成四个 32 位字 P0..P3。加密先用 WK0、WK1 对 P1、P3 做白化，再执行 GFN4，最后用 WK2、WK3 做白化： text T0 = P0 T1 = P1 XOR WK0 T2 = P2 T3 = P3 XOR WK1 Y = GFN4(RK0..RK(2r-1), T) C0 = Y0 C1 = Y1 XOR WK2 C…

为什么值得读

RFC 6114 说 CLEFIA 是 2007 年基于当时最新技术设计的轻量级 128 位分组密码。它能在 0.13 微米标准 CMOS ASIC 库中实现于 3 Kgates 以内，同时提供 128/192/256 位安全强度和较高的软硬件性能；许多轻量级算法牺牲安全性或速度，CLEFIA 试图在两者之间取得平衡。它被提议纳入 ISO/IEC 29192-2 和日本 CRYPTREC 的电子政务推荐密码修订。RFC 6114 第 7 节说，CLEFIA 的完整轮在公开评审中没有发现安全弱点，设计者和独立密码学家都没有报告。这是 2011 年 RFC 的评估，不是对全部攻击模型的形式化证明。

边界与攻击面

RFC 6114 的「no security weaknesses have been found for full-round CLEFIA to date」（完整轮未发现弱点）是 2011 年文档中的公开评审总结，不是对全部攻击模型的形式化证明，也不保证未来不会出现更好的分析方法。本文不把它扩大成绝对安全结论，也不引用未经本文核实的攻击论文来宣称 CLEFIA 已被攻破。CLEFIA 的部署位置需要区分：它是 Sony 设计的轻量级算法，2007 年发表，被提议纳入 ISO/IEC 29192-2 和 CRYPTREC 的电子政务推荐密码修订；ISO/IEC 29192-2:2019 正式把它与 PRESENT、LEA 并列为轻量级分组密码。本文不把它说成通用协议的默认算法； 被标准化 不等于 在所有协议中默认可用 。…
