对称密码

层级 3term对称分组密码

这一课要解决什么

读完这一课，你能用自己的话解释「对称密码」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

术语 ：对称密码（Symmetric Cryptography）。定义句是：「A branch of cryptography in which the algorithms use the same key for both of two counterpart cryptographic operations (e.g., encryption and decryption).」条目接着给出 See 与 Compare 两条交叉引用：对照词是非对称密码，另一称呼是 secret-key cryptography。…

为什么值得读

为什么要单列这一分支：同一条目的教程段先给历史再给示例——它把对称密码的使用推到数千年之前，并在句中标注它所引的史学作者，随后点名 AES 作为现代示例。分支划分的价值在于把 共享密钥 这一前提独立出来：一旦它成立，密钥分配与保密就成了主要成本，而这正是条目接下来说明的劣势；把这一支与其非对称对照分开叙述，才让选型讨论有可指认的对象。

边界与攻击面

限度写在条目自己的教程里：「Symmetric cryptography has a disadvantage compared to asymmetric cryptography with regard to key distribution.」它给的例子是一段单向的双人通信：Alice 用一把密钥加密她要发给 Bob 的数据，Bob 用同一把密钥解密，而把共享密钥保密本身就带来成本与风险——密钥要分发到两端即是暴露面。因此这一分支的代价不在算法强度，而在共享密钥的分发与保管；条目末尾的两条交叉引用也正是 key distribution 与 key management。
