吉尔伯特·弗纳姆

层级 3personOTP 与流密码

这一课要解决什么

读完这一课，你能用自己的话解释「吉尔伯特·弗纳姆」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

人物 ：吉尔伯特·弗纳姆（Gilbert Vernam）。本行是人物行，其原理对应贡献而非算法叙述。Shannon 的 1949 年论文第 1417 行印出「This type of perfect secrecy is realized by the Vernam system.」，把该类型完美保密的实现归到以 Vernam 命名的系统。因此该条目把弗纳姆定位为这一系统的命名者与发现者，不把完美保密的证明归给他；一次性密码本的机制与完美保密定理由 one-time-pad、perfect-secrecy、shannon-perfect-secrecy 行承载。

为什么值得读

其系统的设计条件与变体边界由 Shannon 印出。第 3081 行说「If the size of the key is not limited the Vernam system can be used.」，即密钥长度不受限制时可以使用该系统；第 2324 行说「running key ciphers can usually be solved uniquely」，并把 running key cipher 定义为把随机字母序列换成有意义文本的 Vernam type system。该条目只主张这些印出的条件与变体关系，不把 running key 变体等同于一次性密码本，也不把密钥不受限制外推为工程上可无限扩展。

边界与攻击面

边界由 HAC 印出：第 2615–2616 行说 Moscow-Washington hot-line 不再「secured with a one-time pad, which has been replaced by a symmetric-key cipher」。该条目只说实际部署被更短密钥的对称密码替换，不称 Vernam system 已被攻破；running key 变体的可解性由 Shannon 论文的 why 节承载，不在本行展开。
