平分问题（PARTITION）NP 完全性

层级 4theorem理论基础

这一课要解决什么

读完这一课，你能用自己的话解释「平分问题（PARTITION）NP 完全性」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

定理 ：平分问题（PARTITION）NP 完全性（NP-Completeness of PARTITION）。 判定问题 输入多重集 S={a 1,…,a r}，总和 ΣS=2B；问是否存在子集 T⊆S 使 ΣT=B。证书就是 T：只需把 T 中元素相加并与 B 比较，验证时间是 O(r)，所以 PARTITION ∈ NP。 Karp 归约 Karp 1972 从 KNAPSACK 归约。给定 (a 1,…,a r,b)，构造 c i=a i (i=1,…,r)， c {r+1}=b+1， c {r+2}=Σa i+1−b。新集合总和为 Σc=2(Σa i+1)，令 B′=Σa i+1。…

为什么值得读

PARTITION 是“把数分成两组使和相等”的最短判定形式。它把 NP 完全性、证书验证、归约方向与伪多项式 DP 放在同一条链上，适合说明“问题难”与“所有实例都难”不是一回事。它是组合判定问题，不是密码算法；与子集和、背包、精确覆盖相邻，但目标函数和归约链不同。密码学中的困难性还需要平均-case 分布与具体安全归约，不能直接由 NP 完全性推出。

边界与攻击面

1.特殊情况：所有数相等、B 很小或有很多重复值时，实例很容易；NP 完全性只说明存在难实例族。2.伪多项式：O(rB) 的 DP 在 B 的二进制长度 n 下可能是 2^n 级；不能声称多项式时间。3.归约方向：把 PARTITION 归约到 KNAPSACK 只能证明 PARTITION 在 KNAPSACK 的难度之内，不能证明 KNAPSACK 难。4.密码学边界：NP 完全性不提供平均-case 困难性、随机自归约或具体安全参数；该条目不给密码协议证明。
