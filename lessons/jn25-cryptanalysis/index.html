JN-25 破译

层级 4attack破译方法

这一课要解决什么

读完这一课，你能用自己的话解释「JN-25 破译」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

攻击 ：JN-25 破译（JN-25 Cryptanalysis）。 码本与叠加 JN-25 先把日文电文查五位数码本，得到码组 x i；再从加法簿取五位数 k i，按十进制逐位模 10 相加： c i=(x i+k i) mod 10。这不是二进制异或，而是逐位不进位加法；接收方用同一加法簿逐位相减还原码组。加法簿按页/行组织，电文开头的指示组指出所用页与行。 深度与码本恢复 同一加法簿页被多条电文复用时，两条密文逐位相减： c i⊖c i′=(x i⊖x i′) mod 10。加法被消去，剩下码本码组的差。大量“深度”加上已知码组、猜测的 crib 和频率分析，可以恢复码本含义；再把新码组反查，逐步读出明文。

为什么值得读

JN-25 是“码本 + 加法超加密”的典型。它的弱点不是加法算法本身，而是加法簿的重复使用和码本规模有限；一旦深度足够，统计攻击就能把一次性掩码变成可分析的码本差分。VENONA 同样利用一次性密码本页重复，但 VENONA 的失败点是“OTP 页重复”；JN-25 的加法簿本来就不是 OTP，重复使用是设计常态，深度更容易积累。两者不能当成同一种密钥复用错误。

边界与攻击面

1.加法簿更换：换页/换簿会使已有深度失效，必须重新积累。2.码本扩充：新码组没有已知含义，只能靠上下文猜。3.指示组或抄收错误：逐位相减会产生大量乱码，需 garble check。4.不是现代密码：JN-25 的码本+加法结构不等价于现代流密码或分组密码；不能把历史破译直接外推到 OTP 或 AES。
