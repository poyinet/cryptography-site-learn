RSA 公钥密码

层级 2algorithm非对称公钥

这一课要解决什么

读完这一课，你能用自己的话解释「RSA 公钥密码」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

算法 ：RSA 公钥密码（RSA）。RSA 先是一对整数上的模幂运算；保密加密和数字签名还必须各自配上不同的编码、参数与验证规则。该条目解释目录实体 algorithm--rsa，限定为两素数 RSA，再说明 OAEP/PSS 怎样使用这些原语。它不替代 RFC 8017 标准条目的详解，也不是可部署的密码服务。 消息字节与整数代表 设 n 的位数为 modBits，k=ceil(modBits/8) 是模数字节长度。RSAEP 的输入 m、输出 c 都属于 0…n−1；RSADP 对同样范围的密文代表求逆。0 和与 n 不互素的代表没有被排除。超出范围应报错，不能擅自先取模，让不同输入悄悄变成同一个代表。用户消息 M 则是字节串。…

为什么值得读

知道(n,e)就能做公共方向模幂，掌握正确私钥材料则能做逆运算。这把公开地址与需要保密的能力分开。知道因子p、q可求λ(n)并恢复相应d，因此因子必须保密；但已有分解即可求逆不等于任何RSA求逆算法都等价于分解。后一个等价关系不能当作已证明的普遍定理。 一条清楚的工程分界 整数置换、加密方案、签名方案、证书和协议解决不同问题。OAEP把消息编码后送入加密原语；PSS为签名构造可检查的代表。身份归属还要靠密钥认证与协议上下文。把层次分清，才能解释为何裸RSA的正确性不产生现代保密性，也不自动产生不可伪造的签名结论。

边界与攻击面

裸RSA在固定密钥下是确定的：同一代表总得到同一密文。消息若只有少数已知候选，任何人都可用公钥加密候选后比较。乘法结构又给E(m1)E(m2) modn=E(m1m2 modn)。例子中不知私钥也可把65的密文变成130的密文。这说明可篡改性，不是普遍的免费解密算法；经过OAEP后，不能把等式直接解释成用户消息也这样相乘。 不能把全部风险归结为分解n 重复或不合条件的素因子、错误指数条件、私钥泄漏、弱随机源、错误编码检查都可能破坏系统。小指数若直接作用于未预处理的小消息，还可能在未模回绕时暴露普通整数幂。某个e的名字不是单独安全开关，分解困难也不能修复这些方案和实现错误。 错误反馈可能变成信息 OAEP解码须检查长度、范围、前导字节、标签哈希及DB结构。不同失败原因若经响应或时间被区分，就可能给选择密文攻击提供信息。PKCS 1 v1.5加密与PSS签名不是同一方案，不能因为共享PKCS 1名称就共用解析规则。…
