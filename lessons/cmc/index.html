CMC 宽块加密模式（CBC–Mask–CBC）

层级 3algorithm对称分组密码

这一课要解决什么

读完这一课，你能用自己的话解释「CMC 宽块加密模式（CBC–Mask–CBC）」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

算法 ：CMC 宽块加密模式（CBC–Mask–CBC）（CMC wide-block enciphering mode (CBC–Mask–CBC)）。 CBC–Mask–CBC CMC 把 n 位分组密码变成作用在 mn 位字符串上的 tweakable enciphering scheme（m≥2）。加密先做一遍 CBC 加密，得到一个链值；用首尾链值导出掩码，xor 到每个中间块；再做一遍 CBC 解密。解密对称：先 CBC 加密，xor 同一掩码，再 CBC 解密。名字就是 CBC–Mask–CBC。…

为什么值得读

磁盘按扇区读写，一个扇区通常 512 字节；如果逐块 ECB，攻击者可以重排、替换或复制块。CMC 把整个扇区当成一个宽块，任何一块改变都会扩散到全扇区，且同一扇区号+同一明文才得到同一密文。它不需要 universal hash，也不引入额外原语，适合就地加密。 设计取舍 CMC 的扩散来自 CBC 链和全局掩码，不需要 EME 的混合层；代价是两遍顺序执行，无法把扇区内的块并行化。它用两把密钥，密钥编排比单密钥模式多一份材料；换来的证明是 tweakable strong PRP，而不是弱 PRP。

边界与攻击面

CMC 只提供机密性，不产生认证标签；攻击者改一个密文块，解密结果会变成另一段看似随机的明文，接收方无法察觉。tweak 必须唯一：同一 tweak 下重复加密同一明文，密文完全一样，会泄漏相等关系。两遍顺序结构带来延迟，m=1 的单块也不在定义域内。 边界条件 CMC 要求 m≥2，不能直接加密单个分组；解密端要先验证块数，否则会把不完整扇区送进错误路径。tweak 长度是 n 位，扇区号超过范围就要换密钥或换编码。它不抵抗流量分析，也不隐藏扇区访问模式。
