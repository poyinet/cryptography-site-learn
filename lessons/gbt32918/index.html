SM2 公钥密码算法

层级 2standard中国国密

这一课要解决什么

读完这一课，你能用自己的话解释「SM2 公钥密码算法」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

标准 ：SM2 公钥密码算法（SM2 Public Key Cryptography Algorithm）。 曲线与密钥 SM2 在 256 位素数域椭圆曲线上实现签名、加密和密钥交换，签名把 SM3、用户 ID 与曲线参数绑定。基点 G 的阶为 n，私钥 d 在 [1, n−1]，公钥 P = [d]G。标准分五部分：总则、数字签名、密钥交换、公钥加密、参数定义。 签名 签名先计算 ZA = SM3(ENTL ID a b xG yG xA yA)，再计算 e = SM3(ZA M)。选随机 k，计算 (x1,y1) = [k]G，r = (e+x1) mod n；若 r = 0 或 r+k = n 重选。…

为什么值得读

SM2 是中国商用密码体系的公钥底座。它用一条 256 位曲线同时承载签名、加密和密钥交换，并用 SM3 把用户身份、曲线参数和消息绑定进签名，形成可互操作的国密公钥基础设施。与 RSA 相比，SM2 的密钥和签名更短，签名速度更快；代价是曲线参数、用户 ID 和随机数 k 的管理更复杂。它的价值不是“替代某一个算法”，而是把证书、电子签章、TLCP 和金融终端拉到同一套公钥标准上。

边界与攻击面

SM2 的安全性依赖椭圆曲线离散对数、SM3 和随机数 k。k 重用、偏置或故障注入会泄露私钥；曲线参数替换、无效点攻击、侧信道和错误处理也是现实风险。
