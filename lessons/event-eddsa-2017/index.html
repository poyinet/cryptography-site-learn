Ed25519 进入 RFC

层级 2event数字签名

这一课要解决什么

读完这一课，你能用自己的话解释「Ed25519 进入 RFC」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

事件 ：Ed25519 进入 RFC（Ed25519 Published in RFC 8032）。RFC 8032 摘要写明：「This document describes elliptic curve signature scheme Edwards-curve Digital Signature Algorithm (EdDSA).The algorithm is instantiated with recommended parameters for the edwards25519 and edwards448 curves」。…

为什么值得读

强度取向写在 §1：「Ed25519 is intended to operate at around the 128-bit security level and Ed448 at around the 224-bit security level.A sufficiently large quantum computer would be able to break both.」§8.5 给出选型建议：Ed25519「is widely implemented and has many high-quality implementations」，因此「if a high 128-bit security level is enough, use of Ed25519 is RECOMMENDED; otherwise, Ed448 is RECOMMENDED」。

边界与攻击面

文档中的强制要求是技术性的而非部署性的：§5.1 规定「The context (if present at all) MUST be empty」，§8.7 要求「the receiver MUST buffer the entire message」；并且 §1 明确足够大的量子计算机可破解两者。该条目不使用 强制部署 、 已取代 DSA 等该文件未陈述的表述。
