选择目标攻击

层级 4attack破译方法

这一课要解决什么

读完这一课，你能用自己的话解释「选择目标攻击」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

攻击 ：选择目标攻击（Chosen-Target Attack）。 先把“选择目标攻击”限定清楚 以 Chaum 的 RSA 盲签名为例。签名者公钥为 (N,e)，私钥指数 d。用户想把消息 m 取得签名，但不愿让签名者看到 m： 1.选随机盲化因子 r，计算 m′ = r^e · H(m) mod N； 2.把 m′ 发给签名者，得到 s′ = (m′)^d mod N； 3.去掉盲化，s = r^{-1} · s′ mod N。s^e = (s′)^e · r^{-e} = m′ · r^{-e} = H(m) mod N。签名者只看到 m′，不知道 m；用户得到对 m 的有效签名。…

为什么值得读

盲签名的隐私目标与普通签名不同：签名者不知道消息内容，因此不能按消息做访问控制。若安全性只要求“不能伪造一个新消息的签名”，攻击者可能通过一次签名查询得到多个可用签名，破坏电子现金的“一次提取、一次花费”记账。one-more unforgeability 把“查询数”和“有效签名数”直接比较，正好覆盖这种超额伪造。 chosen-target 与 known-target 的区别 known-target 要求攻击者求逆所有给定目标；chosen-target 允许它只挑一部分目标求逆，只要数量超过查询数。Bellare 等人的主要结果之一是这两个问题多项式等价；因此证明其中一个难，就足以支撑 Chaum 方案的安全性。这个等价性是归约结果，不意味着两个游戏在实现上完全一样。盲签名还依赖盲化函数的正确性、签名者的状态管理、随机数质量和防止重复消费的机制。…

边界与攻击面

1.不是通用 RSA 攻击。chosen-target inversion 假设 RSA 求逆难；它不提供分解 N 的方法。2.不是对所有盲签名成立。不同盲签名方案的盲化关系与困难问题不同；不能把 Chaum 的归约直接套到盲 Schnorr 或盲 BLS。3.盲化不自动带来不可伪造。一个方案可以完全隐藏消息，但仍然允许一次查询生成多个签名；隐私与不可伪造是两个独立目标。4.随机预言机模型。Chaum 方案的证明在 ROM 中；标准模型中的实例化需要额外论证。5.签名者状态与重复消费。若签名者不记录已签的盲化值，或用户能重复使用同一签名，one-more 模型之外的工程攻击仍可能发生。6.盲化因子质量。r 可预测或重复会使消息关联、隐私泄漏，甚至破坏代数关系。
