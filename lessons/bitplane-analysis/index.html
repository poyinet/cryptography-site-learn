位平面分析

层级 3attack隐写与信息隐藏

这一课要解决什么

读完这一课，你能用自己的话解释「位平面分析」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

攻击 ：位平面分析（Bit-Plane Analysis）。 位平面分解 把一幅 8 位灰度图写成像素矩阵 I(x,y)，第 k 个位平面为 b k(x,y) = ⌊I(x,y) / 2^k⌋ mod 2。k=0 是最低比特平面（LSB），k=7 是最高比特平面。高位平面保留轮廓，低位平面看起来更接近噪声。LSB replacement 只改 k=0，因此它不会改变图像的大尺度亮度，却会改变 LSB 平面的局部相关性。 LSB 翻转函数 对像素值 x，定义 F(x) 为把最低比特翻转：偶数 x 变成 x+1，奇数 x 变成 x-1；F₋₁ 则把偶数 x 变成 x-1、奇数 x 变成 x+1。…

为什么值得读

自然图像的 LSB 并不完全随机：传感器噪声、量化、去马赛克和压缩会让相邻像素的低位存在相关性。LSB replacement 用消息位覆盖这一层，等于把局部相关结构替换成近似独立位，位平面纹理与 RS 计数都会变化。 与卡方分析的差别 卡方分析看相邻取值桶的直方图，位平面与 RS 分析看空间分组和翻转后的判别函数。前者对全局直方图敏感，后者对局部纹理和分组结构敏感；两者可以互补，但都主要针对朴素 LSB replacement。 对隐写设计的含义 要抵抗位平面与 RS 检测，嵌入器不能简单地逐位替换，而要使用矩阵嵌入、湿纸编码、F5、自适应嵌入或扩频，使修改位置与修改方向接近载体分布。仅把消息加密后写入 LSB 并不等于不可检测。

边界与攻击面

1.非 LSB replacement：LSB matching、矩阵嵌入、F5、湿纸编码不保证 RS 计数按同一方式变化。2.低嵌入率：少量修改被载体噪声和压缩痕迹淹没。3.强压缩、裁剪、缩放、滤波或重采样：位平面相关结构被破坏，校准失效。4.载体本身纹理单一或经过合成：R/S 基线偏移，容易产生假阳性。5.自适应嵌入：修改集中在纹理区域，全局 RS 统计被稀释。6.调色板图像或索引图：LSB 改动可能映射到完全不同的颜色，视觉与统计假设都改变。位平面纹理是视觉线索，RS 是统计检验；两者都不能证明消息内容，也不能证明没有消息。它们给出的是“像不像 LSB replacement”的证据强度，必须与载体类型、嵌入器和校准样本一起报告。
