CBC 分组模式

层级 3term对称分组密码

这一课要解决什么

读完这一课，你能用自己的话解释「CBC 分组模式」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

术语 ：CBC 分组模式（Cipher Block Chaining (CBC)）。CBC（Cipher Block Chaining，密文分组链接）把明文切成固定长度的块，并在加密每个块之前，先把前一个密文块与当前明文块异或。第一个块没有前一个密文块，因此使用初始化向量 IV 作为起始链接值： text C 1 = E K(P 1 xor IV) C i = E K(P i xor C {i-1}) (i = 2) text P 1 = D K(C 1) xor IV P i = D K(C i) xor C {i-1} (i = 2) 加密必须按顺序进行，因为 C i 依赖 C {i-1}；…

为什么值得读

ECB 对相同明文块产生相同密文块，会泄露重复结构。CBC 通过链接把位置信息混入每个块，使相同明文块在不同位置通常得到不同密文块，从而隐藏这种直接重复。这使 CBC 成为最早被广泛标准化的机密性模式之一。但 CBC 只提供机密性，不提供完整性。它既不能发现密文被修改，也不能发现填充被伪造；这些性质必须由协议层的 MAC 或 AEAD 提供。以为用了 CBC 就等于消息未被篡改，是模式层最常见的误解。CBC 的安全高度依赖两个工程细节：IV 如何产生，以及填充错误如何报告。算法公式正确，但 IV 可预测或错误信息可区分，仍然会导致实际攻击。理解 CBC 的价值，主要在于理解这两个边界。

边界与攻击面

CBC 的 IV 不需要保密，但必须不可预测。如果攻击者能预测下一个 IV，就可以构造明文，使首块加密结果与目标相等，从而判断目标首块的内容；这类选择明文区分 attack 针对的是 IV 生成，而不是 AES 本身。 位翻转与可延展性 CBC 解密把 D K(C i) 与 C {i-1} 异或。修改 C i 会不可预测地破坏 P i，但会让 P {i+1} 的同一比特发生可预测翻转；修改 IV 则会可预测地翻转 P 1 的对应比特。攻击者不需要密钥就能对明文做受控修改，因此 CBC 的机密性不等于完整性。 填充 oracle 如果解密端对填充有效和填充无效给出可区分的行为（不同的错误消息、不同的响应时间或不同的连接状态），攻击者就可以利用这个侧信道，逐字节恢复明文或伪造密文。Vaudenay 在 2002 年系统化了这类 padding oracle 攻击；修复方式不是换一个填充值，而是认证密文并在验证失败时统一拒绝。…
