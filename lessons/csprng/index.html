密码学安全伪随机数发生器

层级 2algorithm随机数与 CSPRNG

这一课要解决什么

读完这一课，你能用自己的话解释「密码学安全伪随机数发生器」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

算法 ：密码学安全伪随机数发生器（Cryptographically Secure PRNG）。§1 开篇给出这类机制的定性：「This Recommendation specifies techniques for the generation of random bits that may then be used directly or converted to random numbers when random values are required by applications using cryptography.」即它规定的是比特生成技术，随机数只是其下游转换物。…

为什么值得读

该条目单列，是因为它把随机数与 CSPRNG中的算法落到可核证据：有可指认的参与者、可复算的步骤，或有馆藏、档案、标准编号支撑的实物与文本。相邻条目只用于定位，不并入该条目，也不替别条作证明。

边界与攻击面

限度写在 §1 的系统性说明里：「The security provided by an RBG that uses a DRBG mechanism is a system implementation issue; both the DRBG mechanism and its randomness source must be considered when determining whether the RBG is appropriate for use by consuming applications.」也即机制本身合格并不等于整个发生器合格，上游随机源必须一并评估。…
