消息认证码

层级 3term消息认证与 AEAD

这一课要解决什么

读完这一课，你能用自己的话解释「消息认证码」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

术语 ：消息认证码（Message Authentication Code (MAC)）。消息认证码用共享密钥对消息生成短标签，接收方用同一密钥验证。它提供完整性和来源认证，但不提供不可否认性；HMAC、CMAC、GMAC 是常见构造。

为什么值得读

MAC 让接收方验证消息来源与完整性；无密钥的哈希只检测篡改，且哈希值完整性需另行保护。

边界与攻击面

MAC 依赖秘密密钥；秘密密钥泄露会破坏认证。上位概念说明它属于哪一类；区别特征说明它与相邻术语的差异；边界说明哪些对象不属于它。正例必须落在外延内，反例必须刚好跨过边界；只给一个同义词不算定义。
