代换-置换网络

层级 3term对称分组密码

这一课要解决什么

读完这一课，你能用自己的话解释「代换-置换网络」在密码学里解决什么问题、它依赖什么假设，以及至少一个会失效的边界。

术语 ：代换-置换网络（Substitution-Permutation Network (SPN)）。定义句是 HAC 第七章的 Definition 7.79：「A substitution-permutation (SP) network is a product cipher composed of a number of stages each involving substitutions and permutations (Figure 7.7).」要点在 每个阶段同时做两类事 ：既不是先全部代换再全部置换，也不是一种新的单表替换；它是积密码的一种形状，图 7.7 给框图，该条目只按散文定义叙述。

为什么值得读

为什么要与迭代结构一起读：该定义之后紧接一句说许多 SP 网络都是 Definition 7.80 意义上的迭代密码，而 7.80 是「An iterated block cipher is a block cipher involving the sequential repetition of an internal function called a round function.」。注意量词：原文写 many，并非全部；参数包括轮数 r、分组位长 n，以及导出各轮子密钥的输入密钥位长 k——可分析性正来自 同一轮函数被重复 这一形状。

边界与攻击面

两条限度分别来自定义与该章注记。其一是对可逆的要求：迭代密码的 Definition 7.80 规定「For invertibility (allowing unique decryption), for each value Ki the round function is a bijection on the round input.」这是对迭代密码的一般要求，SPN 只是其中常被迭代使用的一族。其二在注记节的对照：Feistel、Notz 与 Smith 既讨论抽象 Feistel 结构（并建议配合不可逆的 S 盒使用），也讨论基于可逆（彼此不同）S 盒的 SP 网络——两类结构对盒的可逆性要求不同，这一点是注记写出的，而不是 Definition 7.81 本身。
